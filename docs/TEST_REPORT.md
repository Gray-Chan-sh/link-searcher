## 一、测试概述

### 1.1 测试目的

验证 Link-Searcher 桌面全文搜索应用的**用户界面功能完整性**——每一个页面能加载、每一个按钮/输入框/下拉框/开关响应正确、用户从搜索到索引到 AI 聊天的完整旅程走通。

### 1.2 测试方法

| 维度 | 说明 |
|------|------|
| **驱动方式** | 通过 `tauri-plugin-mcp` 的 `execute_js` 在真实 App webview 中注入 JavaScript，驱动点击、输入、导航、断言 |
| **断言方式** | `execute_js` 返回 DOM 查询结果（元素存在/数量/文本匹配/CSS class/路由 hash），与预期值比对 → PASS/FAIL |
| **截图证据** | 每步操作后调用 `take_screenshot` 截取真实 webview 画面，保存为 PNG |
| **交互兼容** | 针对 React 18+ 特性，使用原生 value setter 注入输入、`MouseEvent` 触发点击（普通 `el.value`/`el.click()` 不触发 React 合成事件） |
| **自动化率** | 101/101 用例全自动判定（0 个需人工判定） |
