# 第十一章：常见问题

> 搜索、索引、OCR、音频、资源占用等常见问题。

---

## 搜索相关

### Q：搜索速度如何？

A：10 万文档级检索延迟 < 50ms，毫秒级响应。搜索速度与索引规模、查询复杂度有关。

### Q：中文搜不到？

A：可能原因：
1. 文档不是 UTF-8 编码
2. 文件尚未完成索引（检查索引状态页）
3. 文件被排除规则过滤
4. 文件内容为空或无法提取

PaddleOCR 内置支持中英文，无需额外配置。

### Q：模糊搜索如何工作？

A：容错编辑距离为 1，自动纠正拼写错误。例如 `finantial` 也能匹配到 `financial`。

### Q：搜索建议如何工作？

A：输入关键词时，搜索框下方自动显示补全建议。建议基于索引中已存在的词汇前缀匹配。

### Q：如何导出搜索结果？

A：搜索页点击「导出」按钮，选择保存路径，以 CSV 格式导出。导出的 CSV 包含文件名、路径、摘要、评分等信息。

### Q：CSV 导出乱码怎么办？

A：用 UTF-8 编码打开导出的 CSV 文件。Excel 打开时可能需要使用「数据 → 从文本/CSV」导入并选择 UTF-8 编码。

## 索引相关

### Q：文件未索引怎么办？

A：可能原因：
1. 文件被排除规则匹配（检查资料库配置中的排除模式）
2. 文件权限不足（应用无法读取）
3. 格式不支持（检查文件类型页面）
4. 文件损坏

在浏览页查看失败状态，悬停 ⚠️ 图标查看具体失败原因。

### Q：索引占多大空间？

A：索引体积约为原始文档的 2–25%，取决于文档类型和内容重复度。纯文本文件的索引比图片/PDF 更小。

### Q：如何重建索引？

A：进入索引状态页面 → 点击「重建索引」按钮 → 确认。系统会清空所有索引数据并重新全量扫描。

### Q：如何知道索引进度？

A：索引状态页查看统计卡片和进度条。底部状态栏实时显示当前扫描进度和文件处理状态。

### Q：增量扫描和全量扫描有什么区别？

A：增量扫描只处理新增和修改的文件（对比文件修改时间），速度快。全量扫描重新遍历所有文件，耗时较长但更彻底。

### Q：索引过程中可以关闭应用吗？

A：可以。索引进度会保存，下次启动时继续。但建议等待当前批次的文件处理完成，避免重复处理。

## OCR 相关

### Q：支持哪些图片格式？

A：PNG、JPG、JPEG、GIF、BMP、WebP、TIFF。系统会自动对图片进行 OCR 文字识别。

### Q：扫描件 PDF 能搜索吗？

A：可以。扫描件 PDF 会自动渲染为图片（200 DPI），然后通过 OCR 识别文字，与普通文档一样可搜索。

### Q：PaddleOCR 需要安装吗？

A：不需要。PaddleOCR 引擎（PP-OCRv5 模型）已内置，使用纯 Rust ONNX 推理（tract），模型编译进二进制（约 21MB），开箱即用。

### Q：PaddleOCR 和 Tesseract 有什么区别？

A：PaddleOCR 是内置引擎，无需安装，零依赖。Tesseract 是备选引擎，需要自行安装 CLI，但支持更多语言。

### Q：如何提高 OCR 识别率？

A：1. 确保图片清晰、文字对比度高 2. 选择正确的 OCR 语言 3. 调整扫描件 PDF 的 DPI 设置（pdftoppm 渲染）

## 音频相关

### Q：支持哪些音频格式？

A：mp3、wav、m4a、aac、flac、ogg、opus、wma。

### Q：如何使用音频识别？

A：首次使用时，在设置页点击「下载 FunASR 模型」（约 850MB）。下载完成后，音频文件会自动进行语音识别，无需额外操作。

### Q：音频识别需要联网吗？

A：不需要。FunASR 模型使用纯 Rust 推理（sherpa-onnx），无需 Python 或 torch，下载完成后完全离线可用。

### Q：支持方言识别吗？

A：支持吴语、粤语、闽语等 7 大方言。

### Q：音频文件有长度限制吗？

A：目前限制为 30 分钟以内的音频文件。超过 30 分钟的音频会被截断处理。

## 资源占用

### Q：内存占用多少？

A：空闲状态约 65MB，扫描过程中 100-200MB，搜索时 80-120MB。

### Q：启动为什么慢？

A：首次启动需要编译 Rust 后端（约 2-5 分钟）。后续启动很快，因为二进制已编译完成。

### Q：CPU 占用高怎么办？

A：OCR 处理期间 CPU 占用会暂时升高（PaddleOCR 使用多核并行处理）。扫描完成后会恢复正常。

## 其他

### Q：支持哪些文档格式？

A：PDF、Word（.doc/.docx）、Excel（.xls/.xlsx）、PPT（.ppt/.pptx）、Markdown、纯文本、代码文件、图片、压缩包（.zip/.tar/.gz/.bz2/.xz）、音频（.mp3/.wav/.m4a 等）。详见文件类型页面。

### Q：如何更新应用？

A：从 GitHub Releases 页面下载新版安装包覆盖安装，数据不会丢失。

### Q：如何卸载应用？

A：删除应用 + 删除数据目录中的文件。数据目录位置见第九章。

### Q：开源吗？如何贡献？

A：MIT 开源。欢迎提交 Issue 和 PR：[GitHub 仓库](https://github.com/Gray-Chan-sh/link-searcher)
