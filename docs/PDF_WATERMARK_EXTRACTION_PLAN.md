## 1. 全局不变量

所有决策都必须服从同一优先级：

```text
不丢正文  >  不误删正文  >  尽量减少水印  >  性能
```

配套硬规则：

1. **正文来源必须在清洗之前确定**。先判“正文在哪一层”，再对选定的那一层去水印。
2. **清洗永远不能成为内容变空的原因**。“最终正文 ⊆ 水印集合”等价于“没有正文”，必须换源。
3. 水印判定**只使用当前文档**的证据，不使用跨文档字典（避免误伤真实姓名/机构名）。
4. **绝不修改原始 PDF**，只影响入库/检索文本。
5. 任何降级、回退、清洗都必须**可追踪**（`body_source` + 标记 + 诊断日志）。

## 2. 子系统在整条管线中的位置

```text
扫描登记（scanner）
   │
   ▼
【提取 Phase 1】  ← OCR + 水印子系统在这里
   1. 页面解析：文字层词+坐标 / 图像覆盖率 / 矢量层 / 旋转
   2. 逐页来源判定：A 纯文字 · B 纯扫描 · C 水印文字层+扫描正文 · D 文字层正文+水印
   3. 按需 OCR（只对需要的层/页）
   4. 全文级水印判定（跨页）
   5. 坐标级清洗
   6. 质量校验 + 回退
   7. 结构还原（阅读顺序 / 表格）
   │
   ▼
【清洗质检 + 落库】content_index + 提取元数据
   │
   ▼
【索引】Tantivy + chunk/嵌入（RAG）
   │
   ▼
【检索 / 问答 / 预览】
```

关键：**第 2 步（来源判定）必须先于第 4–5 步（水印判定与清洗）**。这是本设计最重要的一条顺序约束。

## 3. 页面模型：PDF 的“层”与页面类型

### 3.1 三类层

| 层 | 内容 | 处理 |
|---|---|---|
| 文字层（text objects） | 可选中文字 | 直接抽取，不 OCR |
| 嵌入图像层（扫描栅格） | 整页扫描图 | OCR 这一层 |
| 矢量/覆盖层 | 水印、印章、表单、批注、页眉页脚 | 一般不是正文 |

### 3.2 四类页面（状态机输出）

| 类型 | 判定 | 正文来源 |
|---|---|---|
| A 纯文字页 | 无整页扫描图 + 文字层水平、连续、充足 | 文字层（删除已确认水印） |
| B 纯扫描页 | 有整页扫描图 + 无可信文字层 | 图像 OCR |
| C 水印文字层 + 扫描正文 | 有整页扫描图 + 文字层稀疏/斜向/重复/短碎片 | **图像 OCR**（文字层仅作水印证据） |
| D 文字层正文 + 水印 | 有整页扫描图 + 文字层含连续正文与水印 | 先清洗文字层；不可靠则图像 OCR |

C 类是 `起诉状.pdf`、`20140920.pdf` 的主要路径；D 类是 `1-法庭审理笔录（第二次）.pdf` 的路径。

### 3.3 实测样本

| 文件 | 页面事实 | 正确正文来源 |
|---|---|---|
| `起诉状.pdf` | 4 页整页扫描图；文字层基本是 `陈/骥/X` 水印碎片 | 扫描图 OCR |
| `1-法庭审理笔录（第二次）.pdf` | 整页扫描图；文字层含正文 OCR + 大量斜向水印碎片（约 49.3% 非空行） | 清洗后的文字层，不可靠则 OCR |
| `20140920.pdf` | 扫描表格/执照图；文字层主要是水印碎片和局部验证信息 | 扫描图 OCR，可信验证信息可补充 |

## 4. 逐页来源判定（子系统核心）

现状问题：这些判断散落在 `pdf.rs` / `pdf/watermark.rs` / `pdf/quality.rs`，且主要以**整份文档**为单位。目标：收敛为**一个逐页判定器**。

### 4.1 输入（每页）

- 文字层词 + 坐标、行/块结构、旋转；
- 是否存在整页图像、图像覆盖率、分辨率、编码；
- 文字层非空字符数、密度、水平阅读流比例；
- **跨页重复集合**（全文级，见 6.2）；
- 图像 OCR 的区域与置信度（引擎支持时）。

### 4.2 输出（每页）

- `body_source`：`pdf_text` / `image_ocr` / `hybrid` / `fallback_text`；
- 水印候选坐标集与分类；
- 需要 OCR 的页/区域；
- 质量与回退原因。

### 4.3 判定原则

1. 文字层**不可信**（稀疏/乱码/重复/水印主导）→ 不采纳为正文；
2. 有整页图像且文字层不可信 → OCR；
3. 文字层可信 → 采纳，再做坐标级清洗；
4. 两者互补 → 按区域合并（Phase 4，非默认）；
5. **“文字层是否只是水印”必须在选源阶段判定**，而不是选完再清洗。

## 5. OCR 子系统

### 5.1 引擎与模型能力矩阵

| 引擎 | 平台 | 离线 | 结构能力 | 现状 |
|---|---|---|---|---|
| PaddleOCR PP-OCRv5 mobile（内置） | 全平台 | ✅ | 仅文本 | 默认兜底 |
| Windows OCR | Windows | ✅ | 按行 | 有语言包时系统默认 |
| Apple Vision | macOS | ✅ | 按行 | 系统默认 |
| Tesseract | 全平台 | ✅ | 按行 | 备选，需自装 |
| PP-OCRv5 server / PP-OCRv6 | 全平台 | ✅ | 仅文本 | **候选升级** |
| 版面 + 表格（PP-StructureV3 / RapidTable） | 全平台 | ✅ | 表格/版面 | **候选新增** |
| 文档 VLM（PaddleOCR-VL 等） | 需 GPU | ✅ | 最强 | 疑难页可选，默认关 |

> 实测（本机三样本）：Windows OCR 在**单栏叙述型**（起诉状）明显优于内置 PaddleOCR；在**表格/印章型**（20140920）反而拆碎表格、丢字段值、产生噪声。结论：**没有单一引擎全面占优**，需要按页面类型与成本分层。

### 5.2 渲染与层选择

| 方式 | 取哪层 | 旋转 | 水印 |
|---|---|---|---|
| `pdfimages` | 只取嵌入图像层 | ❌ 不应用 `/Rotate` | 天然避开文字层/矢量水印 |
| `pdftoppm` | 整页渲染 | ✅ 应用 `/Rotate` | 含覆盖层水印 |

规则：旋转页（90°/270°）强制 `pdftoppm`；其余优先 `pdfimages`。

### 5.3 预处理

只保留**有明确收益**的步骤：小图放大到最长边 1000（DBNet 需要）。**不做**灰度、直方图均衡、deskew。

> 实测：旧预处理把同一清晰页面的可识别文本从 435 降到 233，对页面 1/4 块从 270 降到 43。根因是“低对比度”判定用全图 p5/p95 差值，白底黑字页背景占绝大多数像素，差值容易 <100 → 直方图均衡在普通干净页上频繁误触发。

### 5.4 健壮性（已踩过的坑）

| 问题 | 根因 | 对策 |
|---|---|---|
| `[UNK]` | 模型 `use_space_char` 多一个空格类，字典缺该项 | 运行时补空格 token |
| 随机丢页 | 引擎池构建竞态，多线程各建池失败即丢页 | `OnceLock::get_or_init` 只建一次 |
| 整页漏检 | 检测对页面宽度敏感 | 分块检测 + 坐标合并（待做） |
| 旋转页乱码 | `pdfimages` 不应用旋转 | 旋转页走 `pdftoppm` |

### 5.5 成本分层

| 层级 | 成本 | 何时 |
|---|---|---|
| 元数据/坐标 | 低 | 总是 |
| 文字层解析 | 低 | 总是 |
| 页内几何聚类 | 低 | 总是 |
| 图像 OCR | 高 | 仅需要的页 |
| 高 DPI 重试 / 区域二次 OCR | 更高 | 仅失败时 |
| VLM | 最高 | 仅疑难页，默认关 |

## 6. 水印子系统

### 6.1 形态与信号

| 形态 | 主信号 | 能否单页判定 |
|---|---|---|
| 几何型 | 对角链、独占短行、固定间距链 | ✅ 单页 |
| **纯文字层型** | **跨页同位重复** | ❌ 必须全文 |
| 图像型 | OCR 区域跨页一致 | ❌ 必须全文 |

> 纯文字层型（如水平的 `上海小城律师事务所`、`仅供XX使用`）**没有几何异常**，单看一页与正文无异，唯一线索是**整份文档内重复**。因此判定粒度必须是**文档级**。

### 6.2 全文级跨页聚类（主信号）

流程：

```text
逐页取词框 (text, x, y)
  → 归一化坐标 (x/页宽, y/页高)
  → 按“文字 + 归一化位置”聚类
  → 统计每类出现在多少页、位置方差
  → 出现页数 ≥ 阈值 且 位置一致 → 水印候选
```

判定原则：

```text
跨页同位重复（全文级，主信号）
  且（斜向 或 独占短行 或 不属于阅读流）
  且 页面本身差异足够大（排除重复表单）
  → 判为水印候选
```

### 6.3 必须避免的误伤

“每页都重复”的不只是水印：页眉页脚、页码、骑缝章、表头、模板条款、信头、落款、当事人固定信息。因此必须**分类**而非一律删除：

| 分类 | 特征 | 处置 |
|---|---|---|
| `watermark` | 斜向/分散/跨正文/非阅读流 | 删除 |
| `running_header` | 贴页顶、水平、位置固定 | 可降权/剔除 |
| `page_number` | 页边、短数字 | 可剔除 |
| `template_clause` | 正文位置的固定条款 | **保留** |
| `seal` | 印章/骑缝章 | 保留或单独标记 |

### 6.4 删除策略与不变量

- **坐标级删除**，不是字符串删除；
- 同一字符串在正文位置保留；
- 中文碎片不因“像水印”就按字符串删；
- 单页文档无跨页证据时只允许高置信度几何；
- **清洗后正文不足 → 换源，而不是保留空/残**。

## 7. 结构还原（与 PDF 一致）

| 维度 | 要求 |
|---|---|
| 阅读顺序 | 按坐标重排；**禁止左右简单拼接**（会打乱单栏文档行序） |
| 分栏 | 检测列边界后按列读取 |
| 表格/表单 | 需要版面分析 + 表格结构识别（否则挤成一行或被拆碎） |
| 输出粒度 | 纯文本为主；可扩展版面感知（Markdown/JSON）供 RAG |

> 实测：整页 OCR 只识别 416 字符，按宽度二分后 746、2×2 后 768——说明**检测丢行**，而结构还原的前提是先把内容取全。

## 8. 质量验证与回退（统一质量模型）

### 8.1 指标

可打印率、FFFD 比例、OCR 置信度、字符密度、词典命中率、CJK 字间空格比例、`watermark_residual`、`body_source`、正文覆盖率。

### 8.2 状态机

```text
原始文字层
   ↓
检测并尝试清洗
   ↓
清洗后正文覆盖率/密度足够？
   ├─ 是 → 使用清洗结果
   └─ 否 → 图像 OCR
             ↓
         OCR 质量足够？
             ├─ 是 → 使用 OCR
             └─ 否 → 回退原文字层并标记 watermark_residual
```

### 8.3 硬校验

写入前：

1. 正文非空；
2. “最终正文 ⊆ 水印集合” ⇒ 视为无正文，换源。

## 13. 分阶段路线图与验收

| 阶段 | 目标 | 风险 | 验收 |
|---|---|---|---|
| P1 | 逐页来源判定 + 诊断日志（不改结果） | 低 | 三样本逐页决策日志符合预期 |
| P2 | “文字层是否只是水印”强制换源 + 正文⊆水印硬校验 | 中 | 合成样本 C 类不产空、不产水印正文 |
| P3 | 全文级跨页水印聚类（先检测，后删除） | 中 | 三样本命中真水印；页眉/当事人不误伤 |
| P4 | 结构还原（阅读顺序；表格可选） | 中 | 表格样本字段不丢 |
| P5 | 引擎/模型升级（server / v6 / 可选 VLM） | 中高 | 关键词召回率提升且耗时可接受 |
| P6 | 评估体系固化 + 存量重提取 | 低 | 召回率基线可复现 |

### 验收矩阵（沿用）

必测样本：`起诉状.pdf`、`1-法庭审理笔录（第二次）.pdf`、`20140920.pdf`、`证据目录.pdf`（短行表格反例）、`万1.pdf`（含真实机构名反例）、无水印纯文字 PDF、无文字层纯扫描 PDF、单页 PDF、旋转页/竖排/表格/印章页。

验收指标：

- C 类正文必须来自 OCR 或可靠区域合并；
- 三样本正文关键词召回率不下降；
- 反例中的短表格字段、姓名、机构名不得被删；
- 清洗失败不产生空正文；
- `watermark_residual` 可追踪；
- 正常 PDF 输出与改造前一致；
- 平均/P95 耗时与峰值内存有记录；
- `cargo test` / `cargo check` / semgrep ERROR 通过。

## 14. 详细分析：逐页来源判定算法

### 14.1 伪代码

```text
for each page p:
    tl = extract_text_layer(p)            # 词 + 坐标 + 行结构
    img = page_image_info(p)              # 是否有整页图、覆盖率、编码
    wm = cross_page_repeat(p)             # 全文级重复集合（见 15）
    ocr = None

    if img.is_full_page:
        if tl.is_watermark_dominated(wm) or tl.is_sparse or tl.is_garbled:
            ocr = run_ocr(p, source=img)  # B/C 类
            body = ocr
        elif tl.is_reliable and wm.is_empty_or_removable(tl):
            body = tl                     # D 类（清洗后）
        else:
            body = merge(tl, ocr)         # 混合（Phase 4）
    else:
        body = tl                         # A 类（清洗后）
```

### 14.2 `is_watermark_dominated` 判据

- 跨页重复覆盖率 ≥ 阈值（如文字层非空字符中 ≥ 60% 属重复集合）；
- 或清洗后密度 < `50 × 页数`；
- 或重复集合占页内行数 ≥ 阈值且页面间差异大。

### 14.3 顺序约束

判定必须在清洗前。清洗只作用于已确定的 `body`。

## 15. 详细分析：全文级跨页聚类

### 15.1 归一化

```
nx = x / page_width
ny = y / page_height
key = normalize(text)            # 去空白、全角→半角、大小写不敏感
```

### 15.2 聚类与阈值

- 位置容差按页比例给（如 `Δnx ≤ 0.03`、`Δny ≤ 0.02`），而非固定像素；
- 出现页数阈值：`max(2, ceil(0.6 × 页数))`；
- 前置条件：页面内容差异足够大（否则重复表单会误判）；
- 模糊匹配：允许少量字符差（OCR 抖动）。

### 15.3 分类

```
贴页顶/页底 + 水平        → running_header / page_number
斜向 / 分散 / 跨正文      → watermark
正文位置 + 长行           → template_clause（保留）
```

### 15.4 输出

坐标级删除集合（每页一组词框），并附分类标签，供质量审计。

---

## 16. 详细分析：失败模式 1（只提取到水印）的完整链路

### 16.1 触发

文字层 = 水印；图像层 = 正文；提取采纳文字层（因为它非空、够长）。

### 16.2 现有兜底（已实现）

```text
清洗后正文密度不足 → 升级图像 OCR
    ├─ OCR 有内容 → 用 OCR
    └─ OCR 为空  → 回退带水印文字层（不写空）
```

### 16.3 残余缺口

| 缺口 | 后果 |
|---|---|
| `watermark::scan` 返回 `None` | 不检测 → 把水印文字层当正文入库 |
| 全文级检测太弱 | 漏判 → 正文没走 OCR |
| OCR 升级后只删非中文 | OCR 读到中文水印则保留 |
| 普通分支无 `watermark_dominates_text` 守卫 | 覆盖不全 |

### 16.4 目标修法

选源阶段判定“文字层是否只是水印” → 强制换源；写入前硬校验“正文非空且 正文 ⊄ 水印集合”。

## 18. 非目标与边界

- 不对任意单页、同色、同方向、与正文完全融合的水印承诺 100% 自动识别；
- 默认不做图像 mask / inpainting（可能损伤印章、手写、表格线）；
- 默认不引入 ONNX Runtime / GPU（除非模型升级证明必要）；
- 不建立跨文档水印字典。

> 无法高置信度区分时，**保留原文并标记质量问题**，比静默删除真实正文更安全。
