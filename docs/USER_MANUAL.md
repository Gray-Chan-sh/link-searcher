## 进阶：远程访问（Web 模式）

应用启动时**默认自动开启** Web API 服务（设置页「系统 → Web API」可关闭，改后需重启），局域网内其它设备可直接用浏览器访问同一套界面：

1. 打开桌面端 **设置 → 系统 → Web API**，复制「远程访问」地址（形如 `https://192.168.x.x:8443`），并记下下方的 **Bearer Token**（持久化在 `config.json` 的 `web_api_token`，每次启动不变；也可用环境变量 `LS_WEB_API_TOKEN` 注入）
2. 其它机器浏览器打开该地址，首次会提示输入 Token；自签名证书需在浏览器中选择信任一次
3. 登录后功能与桌面端一致（搜索 / 浏览 / 索引 / AI 聊天 / 设置）

**多设备使用与在线状态**（2026-10-15 起，原"单用户 IP 排他"已废弃）：

- **多端可以同时使用**：手机浏览器、电脑浏览器与飞书机器人可并存，不会互相踢下线；
- 设置页的「Web API」区块会显示**最近活跃来源**（IP）与在线记录，可点「清除记录」——
  这只清展示记录，不阻断任何访问；
- **Token 是唯一门槛**：请勿把 8443 端口暴露到公网；局域网内按需使用（如需外网访问，
  推荐用 Tailscale 等私有网络，而不是端口映射）；
- Token 被修改（设置页 / Web 端均可改）会同步写回 `config.json` 并立即作废旧会话，
  持旧 Token 的客户端会掉线重新登录。

## 附录：提取质量体检

### 什么是质量评分

每次索引时，系统自动对提取到的文本计算质量评分（0~1），无需 Ground Truth。评分综合以下五个信号：

| 信号 | 含义 | 异常表现 |
|------|------|----------|
| 可打印字符比例 | 文本中可打印字符占总字符的比例 | 乱码多 → 比例低 |
| U+FFFD 乱码比例 | 替换字符（）的出现频率 | OCR 解码失败 → 比例高 |
| OCR 平均置信度 | OCR 引擎返回的逐字符置信度均值 | 图片质量差 → 置信度低 |
| 字符密度 | 有效文字占文本总量的密度 | 空白/符号过多 → 密度低 |
| 词典命中率 | 文字在常见词典中的匹配率 | 非自然语言 → 命中率低 |

### 水印自动去除

带律所签名/骑缝水印的 PDF，水印文字常被写进文字层而污染索引。系统会用**当前 PDF 的几何特征**自动识别这类水印（如 `X / 3 / 4 / ** / 陈骥` 形式的斜向碎片），并**从入库/检索文本中去除**；当水印占比过高时改用图像 OCR（OCR 通常不识别浅灰水印）。系统不会用其它文档的水印词影响当前文档。

- 只清洗入库文本，**不改动原始 PDF**；
- 若正文无法恢复，会保留带水印文字层（不会写入空正文），并在质量体检中标记为 `watermark_residual`；
- 为不误删正文，`上海`、`律师`、`陈骥` 等**中文**碎片即使判为水印也保留（它们也可能是真实内容）。

### 评分等级

| 颜色 | 分数范围 | 含义 |
|:---:|:---:|------|
| 🟢 绿色 | > 0.75 | 正常 |
| 🟡 黄色 | 0.5 ~ 0.75 | 较低 |
| 🔴 红色 | < 0.5 | 低质量 |
| ⬜ 灰色 | 未评估 | 尚未计算（如跳过的文件） |

### 在哪里查看

- **索引状态页**：「质量体检」卡片展示整体质量分布（各颜色占比），下方列出低质量文件审计清单
- **浏览页**：文件表格新增「质量」列，支持按质量排序和筛选低质量文件
- **预览面板**：选中文件后显示质量评分区块，可直接查看该文件的评分与标记

### 低质量文件审计与重新提取

1. 在索引状态页点击「质量体检」卡片，查看低质量文件清单
2. 支持按最低评分阈值过滤，缩范围定位问题文件
3. 点击「重新提取」，系统尝试用指定引擎重新提取文本

**安全机制**：每个文件最多重试 **3 次**。若每次重试质量提升不足 **0.1**，则标记为「已尽力」（exhausted）并停止重试，避免无效死循环。
