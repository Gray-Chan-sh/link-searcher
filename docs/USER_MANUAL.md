## 附录：提取质量体检

### 什么是质量评分

每次索引时，系统自动对提取到的文本计算质量评分（0~1），无需 Ground Truth。评分综合以下五个信号：

| 信号 | 含义 | 异常表现 |
|------|------|----------|
| 可打印字符比例 | 文本中可打印字符占总字符的比例 | 乱码多 → 比例低 |
| U+FFFD 乱码比例 | 替换字符（）的出现频率 | OCR 解码失败 → 比例高 |
| OCR 平均置信度 | OCR 引擎返回的逐字符置信度均值 | 图片质量差 → 置信度低 |
| 字符密度 | 有效文字占文本总量的密度 | 空白/符号过多 → 密度低 |
| 词典命中率 | 文字在常见词典中的匹配率 | 非自然语言 → 命中率低 |

### 评分等级

| 颜色 | 分数范围 | 含义 |
|:---:|:---:|------|
| 🟢 绿色 | > 0.75 | 正常 |
| 🟡 黄色 | 0.5 ~ 0.75 | 较低 |
| 🔴 红色 | < 0.5 | 低质量 |
| ⬜ 灰色 | 未评估 | 尚未计算（如跳过的文件） |

### 在哪里查看

- **索引状态页**：「质量体检」卡片展示整体质量分布（各颜色占比），下方列出低质量文件审计清单
- **浏览页**：文件表格新增「质量」列，支持按质量排序和筛选低质量文件
- **预览面板**：选中文件后显示质量评分区块，可直接查看该文件的评分与标记

### 低质量文件审计与重新提取

1. 在索引状态页点击「质量体检」卡片，查看低质量文件清单
2. 支持按最低评分阈值过滤，缩范围定位问题文件
3. 点击「重新提取」，系统尝试用指定引擎重新提取文本

**安全机制**：每个文件最多重试 **3 次**。若每次重试质量提升不足 **0.1**，则标记为「已尽力」（exhausted）并停止重试，避免无效死循环。
