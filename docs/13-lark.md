# 第十三章：飞书机器人

> 把本机的私有库接到飞书：**私聊**提问、搜索、把原文件发到飞书。**无需公网** ——
> 机器人用飞书长连接收消息，再经本机 Web API 读写索引与 AI 能力。
>
> - 本章是**使用手册**（怎么用、注意什么）；
> - **接入与设置**见 [第六章 · 集成标签页](06-settings.md#集成标签页)（绑定应用 / 开关 / 白名单 / 配对）；
> - 设计与实测记录见 [`LARK_BOT.md`](LARK_BOT.md)（开发者向）。

---

## 13.1 它能做什么（总览）

| 能力 | 说明 |
|------|------|
| **AI 问答** | 私聊直接提问，基于本地库检索后回答（与桌面端同一套 RAG；配了 Embedding 时有语义融合） |
| **多组多轮会话** | 每个私聊可有多条会话，各自独立多轮；话题明显切换时**自动另起会话** |
| **命令体系** | `/help` `/current` `/history` `/new` `/sessions` `/switch` `/rename` `/stop` `/delete` `/find` |
| **搜索** | `/find 关键词` → 结果卡（文件名 / 路径 / 片段），**每页 5 条**，卡片内可直接翻页 |
| **语义搜索** | 配了 Embedding 时结果卡出现「✦ 语义」开关（与桌面 / Web 同一实现） |
| **发文件到飞书** | 搜索结果卡点「发送 N」→ 把原文件发到当前私聊（图片 / 语音气泡 / 附件） |
| **卡片交互** | 打开详情（进 WebUI 继续追问）/ 换一批证据 / 停止 / 切换 / 删除 / 新建会话 |
| **机器人菜单** | 可选：开发者后台配置，输入框旁常驻（仅单聊），不配也不影响命令 |

> 入站方向（你在飞书里发文件/语音/图片给机器人**入库**）**尚未支持**，见 13.10。

## 13.2 开始之前（三件事）

1. **应用保持运行**：机器人由应用托管，应用一停它就收不到消息（关窗口可以，托盘退出不行）。
2. **已绑定飞书应用 + `lark-cli` 就绪**：按 [第六章 · 集成标签页](06-settings.md#集成标签页) 完成；页面顶部的「飞书接入自检」应全绿（至少 `bot 身份` 是 ready）。
3. **打开总开关 + 把自己加进白名单**：按步骤 12.2 / 12.3 / 12.4 操作。**白名单留空 = 谁都不许**（连你自己也不行）。

> **AI 问答的前置**：问答走的是与桌面端同一套 AI 能力，需要先在「设置 → AI」配置好
> **LLM 网关**（未配置时提问会失败）。只用 `/find` 搜索**不需要** AI；语义搜索另需 Embedding 网关。

> 第一次使用最快的路径：打开总开关 → 点「开始配对」→ 用飞书私聊机器人任意发一条消息 →
> 回到设置页，你的 `open_id` 会自动出现在「允许的用户」里。

## 13.3 直接提问（AI 问答）

在飞书里**私聊**机器人，直接发问题即可（不带 `/`）：

- 回答以**卡片**呈现：先是一张「检索中」卡（有进度、可点「停止」），随后收尾成带**会话名**的回答卡；
- 回答基于本地库检索（与桌面端同一套 RAG）。配置了 Embedding 网关时检索含语义融合；
- **每个私聊同时只生成一条回答**：上一题还在生成时再发，会提示「正在回答上一条问题，请稍候（发 `/stop` 可中止）」；
- 同一私聊里连续提问就是**多轮对话**（历史会带上）；
- 换一个明显不相关的话题时，机器人会**自动另起一条新会话**并提示（旧会话保留，可 `/sessions` 切回）。
  判定很保守：追问、细化、指代（"他/这个案子"）**不会**触发切换。

回答卡上的按钮：

| 按钮 | 作用 |
|------|------|
| **打开详情** | 给出该会话在 WebUI 里的深链（浏览器继续追问；见 13.8） |
| **换一批证据** | 用**换过检索词**的方式重跑原问题（不是原词再搜一遍），适合"材料中不足以回答"时再试 |
| **停止** | 中断正在生成的回答（已生成的部分保留在卡片里；与 `/stop` 同效） |

## 13.4 命令一览

**全英文、以 `/` 开头**。未识别的 `/xxx` 会按普通提问处理（不会"吃掉"你的问题）。

| 命令 | 作用 | 备注 |
|------|------|------|
| `/help` | 命令帮助卡片 | 单独发一个 `/` 也一样 |
| `/current` | 查看当前会话（名字 / 消息数 / 会话总数） | 别名 `/session` |
| `/history` | **召回当前会话的全部内容**（分页卡片） | 别名 `/recall`；超长时提示到 WebUI 看完整版 |
| `/new` | 新建会话并切换过去 | 回一张最新会话列表 |
| `/sessions` | 会话列表卡片 | 点按钮或**回复数字**切换；列表最多显示 5 条（最近使用优先） |
| `/switch 3` | 切到第 3 个会话 | 也支持标题前缀：`/switch 合同`；前缀命中多条会列出候选 |
| `/rename 新名字` | 给**当前会话**改名 | 上限 30 字；桌面/Web 端同步可见 |
| `/stop` | 停止正在生成的回答 | 别名 `/cancel`；检索阶段同样会中断 |
| `/delete 3` | 删除第 3 个会话的**飞书映射** | 先回确认卡（防误删）；内容仍留在本地，见 13.5 |
| `/find 关键词` | 搜索本地库 | 可加页码：`/find 合同 2`；别名 `/search` |

**回复数字点选**：发完列表后直接回 `3` 等于点第 3 个按钮（零配置，不依赖卡片回调）。
仅在"10 分钟内发过列表、数字命中已记录序号、列表 ≥2 项"时才拦截，否则数字照常当提问。
该记忆保存在机器人进程内存里：**机器人重启后失效**，重发一次列表即可。

> ⚠️ **飞书客户端本身不支持"输入 `/` 弹命令列表"**（官方 FAQ 明确机器人不支持斜杠命令）。
> 最接近的是**机器人自定义菜单**（见 13.9），不配置也不影响上面所有命令。

## 13.5 会话管理

- 会话按**飞书私聊**（`chat_id`）绑定：同一个私聊 = 同一组会话；**多端登录同一飞书账号**（手机/桌面/网页）
  是**同一个私聊**，看到的是同一套会话；
- **每个白名单用户各自独立**：你和别人的私聊互不可见、互不干扰；
- 名字默认是**首问的前 20 字**，不满意用 `/rename` 改（上限 30 字）；
- 回答卡与生成中的卡片**页眉（蓝色）以会话名开头**，随时知道自己在哪条会话里；
- 会话在桌面端/Web 端的**默认列表里看不到**（三端隔离：飞书会话属 `origin=lark`）；
  用回答卡的「打开详情」深链可以在浏览器里查看并继续追问；
- `/delete` 删的是**飞书侧的会话映射**（列表项），**对话内容仍保留在本地**
  （`chat_history.json`）；删除后机器人不再提供该会话的深链，桌面/Web 的默认列表也不显示它；
- 如果绑定的会话被**其它端删除**，机器人会提示"原会话已不存在，已自动开一条新会话"并继续。

## 13.6 搜索：`/find`

```
/find 合同          ← 第 1 页（每页 5 条）
/find 合同 2        ← 第 2 页（页码 ≤99）
```

- **每页 5 条**是刻意设计：每条命中占 2–3 行（文件名 + 路径 + 片段），5 条约一屏，且与按钮一一对应；
- 结果卡自带：
  - **「上一页 / 下一页」** —— 点击后**原地更新同一张卡**（不刷屏）；第 1 页没有「上一页」、最后一页没有「下一页」；
  - **「✦ 语义」** —— 用同一关键词按"意思"重搜（**配了 Embedding 才出现**；未配置时不显示，
    避免"点了没变化"）。语义开着但没生效时，页脚会注明原因；
  - **「发送 N」** —— 把第 N 条命中的**原文件**发到飞书（见 13.7）。
- **页码规则**：末尾的纯数字且 ≤99 才算页码 —— `/find 判决书 2024` 里的 `2024` 不会被当成页码；
- 语义搜索的代价：它是**全库向量扫描**，库很大时会明显变慢（5 秒超时自动退回纯关键词）。

## 13.7 把文件发到飞书

在 `/find` 结果卡上点「发送 N」，机器人会把对应的**原文件**发到当前私聊：

| 文件类型 | 发送方式 | 限制 |
|---|---|---|
| 图片（JPG/JPEG/PNG/WEBP/GIF/BMP/ICO/TIFF/HEIC） | 图片消息（聊天里直接预览） | ≤ **10 MB** |
| 图片 10–30 MB、其它文件 | 文件附件 | ≤ **30 MB** |
| `.opus` 音频 | **语音气泡**（可点击播放） | ≤ 30 MB |
| 其它音频（mp3/wav/m4a/…） | 有 ffmpeg 时**转成 Opus** 再发语音气泡；否则按附件发 | ≤ 30 MB |
| 视频（mp4） | 按**文件附件**发（暂不生成封面） | ≤ 30 MB |
| 任意文件 > 30 MB | **发不了**，机器人会提示改用 WebUI 查看 | — |

**注意**：

- 上传文件需要飞书应用有 **`im:resource`**（或 `im:resource:upload`）权限。首次点「发送 N」若报权限错误，
  请到 [飞书开发者后台](https://open.feishu.cn/app) 给应用补该权限并**重新发布版本**；
- 单条消息只能一种类型：机器人先发文件，不会把文字和文件混在同一条里；
- 机器人**只允许发送索引库里的文件**（按 `file_id` 解析，不接受任意路径）；
- 飞书应用级频率限制 1000 次/分钟、同一会话 5 QPS —— 正常人工点击远够用。

## 13.8 「打开详情」与 WebUI 链接

回答卡的「打开详情」会给一条**直达该会话的 WebUI 深链**（形如
`https://<地址>:8443/#/chat?origin=lark&session=<id>`），在浏览器里打开即可继续追问。

**地址是怎么选的**（多网卡机器不用手动判断）：

1. `config.json` 里的 `webui_base_url`（你手配的固定域名/反代，留空 = 自动）；
2. 否则**Tailscale 地址**（`100.64/10`，本机装了 Tailscale 时）—— 同一 Wi-Fi 与异地都能用；
3. 否则**局域网 IP**（只在同一 Wi-Fi 时可用）。

文案里会附上另一个可用地址（"打不开就换这个"）——飞书不提供客户端 IP，
所以机器人**不会去猜**"你的手机是否在同一网络"。

**注意**：

- Web API 是**自签名证书**，浏览器会先提示「不安全」，点「继续访问」信任一次即可；
- 换网络后若地址不在证书 SAN 里，会**再提示一次**（频繁换网络建议配固定域名或 Tailscale）；
- Web API 必须处于开启状态（默认开启），且**应用在运行**；
- 局域网地址打不开的常见原因：手机不在同一 Wi-Fi、防火墙拦截 8443、绑定了 `127.0.0.1`（只允许本机）。

## 13.9 机器人菜单（可选）

飞书客户端不支持 `/` 弹命令列表，最接近的替代是**机器人自定义菜单**（常驻输入框旁，仅单聊）：

1. 打开 [飞书开发者后台](https://open.feishu.cn/app) → 你的应用 → 「机器人能力 → 自定义菜单」；
2. 菜单项类型选**推送事件**，`event_key` 直接填对应命令（如 `/new`、`/sessions`、`/help`；
   需要参数的 `/find` 放不进去，用 `/help` 引导即可）；
3. 保存并**发布应用版本**，约 5 分钟后生效。

应用侧已支持接收菜单点击（把 `event_key` 当命令执行）；**不配置也不影响任何命令**。

## 13.10 需要注意的内容（重要）

### 数据与安全

- **内容会离开本机**：提问、证据片段与回答会经飞书云端传输；配置了远程 AI 网关时还会发给该网关。
  按"个人助手"定位设计，**不要把机器人分享给不信任的人**；
- **访问控制是"白名单 + 仅私聊"**：白名单**留空 = 拒绝所有人**（fail-closed）；陌生人的私聊会被**静默忽略**
  （不确认机器人存在）；群消息只回一句「本机器人仅支持私聊」；
- **配对期间**任何私聊机器人的人都会被写进白名单 —— 配对时别分享机器人；
- Web API 的 **Token 是唯一门槛**（原"IP 排他"已废弃）：不要把 8443 暴露到公网；
  多设备可同时使用（手机浏览器与机器人可并存）。

### 运行前提

- **应用必须保持运行**：关窗口可以（托盘常驻），**托盘退出 / 应用崩溃 = 机器人离线**；
- **不能休眠/睡眠**：睡眠会断开长连接，期间消息可能丢（唤醒后自动重连）；
- 开机自启可在设置页开启（记得用安装版而不是 dev 版）；
- 升级/重启应用期间机器人短暂离线，属正常。

### 飞书侧硬限制

| 限制 | 数值 |
|---|---|
| 图片上传 | ≤10 MB；JPG/JPEG/PNG/WEBP/GIF/BMP/ICO/TIFF/HEIC |
| 文件/语音上传 | ≤30 MB |
| 文本消息体 | ≤150 KB |
| 卡片消息体 | ≤30 KB |
| 频率 | 应用级 1000 次/分钟、50 次/秒；同一会话 5 QPS |
| 语音消息 | 只能是 Opus（机器人会自动转码） |
| 文件归属 | 只能发送本应用上传的文件 |

### 尚未支持（别踩坑）

- **入站文件/语音/图片**：你在飞书里发文件、语音、图片给机器人**不会入库**；
  它们多数会被当成普通消息处理（或回「请直接说出你的问题」），**请勿依赖**；
- **群聊**：仅私聊（改策略需另行评估，未做）；
- **`/` 弹命令列表**：飞书不支持（用自定义菜单或 `/help`）；
- **原生打开/定位文件**：需要桌面 GUI，机器人侧无此能力 —— 用「打开详情」进 WebUI；
- **文字转语音（TTS）**：项目只有语音识别（ASR），机器人只能发送**已有音频**；
- **视频封面**：视频按文件发送，不生成封面图。

### 其它

- **`lark-cli` 会自更新**：不要顺手升级；若升级，请重跑设置页的「飞书接入自检」确认仍正常；
- 回答过长时机器人会分页成多张卡片，或提示到 WebUI 看完整版（飞书卡片有 30KB 上限）；
- 机器人进程由应用托管，**不要手动起/杀**它；改设置后应用会自动重启机器人。

## 13.11 故障排查

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 发消息完全没反应 | 总开关没开 / 白名单为空 / 应用没运行 / `lark-cli` 未就绪 | 依次检查：设置页运行态、白名单、应用是否在跑、自检是否全绿 |
| 陌生人私聊没反应 | **设计如此**（fail-closed，静默） | 把对方加进白名单（或自己用配对） |
| 群里 @ 没反应 | **设计如此**（仅私聊） | 改用私聊 |
| 回答一直不出现 | 上一条还在生成 / AI 网关异常 | 发 `/stop`；检查 AI 设置与日志 |
| 提问报错/提示"回答为空" | 未配置 LLM 网关（或网关不可用） | 「设置 → AI」配置并测试；只用 `/find` 不需要 AI |
| 卡片按钮点了没反应 | `card.action.trigger` 未订阅 | 自检里「卡片回调订阅」为 blocked 时按提示订阅并发布版本 |
| 菜单点了没反应 | 菜单未配置 / 未发布版本 | 按 13.9 配置；不配也不影响命令 |
| 「发送 N」报权限错误 | 应用缺 `im:resource` | 开发者后台补权限并重新发布（见 13.7） |
| 文件发不出去 | 超过 10 MB / 30 MB | 大文件改用「打开详情」在 WebUI 查看 |
| 「打开详情」打不开 | 不在同一网络 / 证书告警 / 防火墙 | 试文案里的备用地址；信任自签名证书；检查防火墙 8443 |
| 会话列表只有 5 条 | 设计如此（最近使用优先） | 用 `/switch <标题前缀>` 切到更早的会话 |
| 会话突然换了/多了 | 自动新话题 / 其它端删除 | `/sessions` 查看并切回 |
| 机器人的回答与桌面端不一致 | 三端会话隔离（飞书会话独立） | 正常现象；用「打开详情」在同一会话里追问 |
| 机器人重复回答同一条消息 | 理论上不会（按 `message_id` 去重） | 若出现，记录日志并反馈 |

更多通用问题见 [第十一章：常见问题](11-faq.md)。

## 13.12 与桌面端 / Web 的差异

| 能力 | 飞书机器人 | 桌面端 / WebUI |
|---|---|---|
| AI 问答 / 多轮 | ✅（独立会话空间） | ✅ |
| 搜索 | ✅ `/find`（每页 5 条 + 翻页 + 语义开关） | ✅（完整搜索页：筛选、排序、预览、导出） |
| 把文件发出去 | ✅ 发到飞书（≤10/30 MB） | — |
| 打开 / 定位文件 | ❌（用 WebUI 深链替代） | ✅ |
| 批量管理 / 目录管理 / 设置 | ❌（去 WebUI 或桌面端） | ✅ |
| 会话列表可见性 | 只看到飞书会话 | 只看到本端会话（`origin` 隔离） |
