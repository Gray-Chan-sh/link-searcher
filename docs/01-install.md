# 第一章：安装与首次启动

> 本章教你下载、安装、启动 Link-Searcher，完成新手引导。

---

## 步骤 1：确认系统要求

在开始安装前，请确认你的电脑满足以下条件：

**下载预编译包（推荐）**：
- macOS 11+（Intel 或 Apple Silicon）
- Windows 10+
- Linux（x86_64）

**从源码运行**：
- Node.js 20+
- Rust 1.85+

## 步骤 2：下载安装包

访问 [GitHub Releases 页面](https://github.com/Gray-Chan-sh/link-searcher/releases) 下载对应平台的安装包：

| 平台 | 安装包 |
|------|--------|
| macOS | `.dmg` |
| Windows | `.msi` |
| Linux | `.deb` 或 `.AppImage` |

打开安装包，按系统提示完成安装。

## 步骤 3：从源码构建（可选）

如果你想体验最新开发版，可以直接从源码运行：

```bash
git clone https://github.com/Gray-Chan-sh/link-searcher.git
cd link-searcher
npm install
npm run tauri dev
```

首次启动会自动编译 Rust 后端（约 2-5 分钟），之后启动很快。

## 步骤 4：首次启动

启动应用后，你将看到以下界面：

![搜索页](screenshots/annotated/search-page-annotated.png)

**界面布局**：
- **左侧导航栏**：8 个页面入口（搜索、AI 聊天、浏览、资料库、索引状态、日志、文件类型、设置）
- **左侧筛选面板**：目录树和文件类型筛选
- **中间主内容区**：搜索框和结果列表
- **底部状态栏**：文件总数、已索引数、OCR 进度、上次扫描时间

## 步骤 5：完成新手引导

首次启动时，会弹出**新手引导向导**（Onboarding Wizard），按提示完成以下步骤：

1. 点击「下一步」阅读功能介绍
2. 了解如何添加资料库
3. 了解如何搜索文件
4. 点击「完成」关闭向导

> 引导完成后，你可以随时通过设置页重新开启引导。

## 步骤 6：初始化依赖（发布版首次启动）

为控制安装包体积，**OCR / 语义 / 音频转写模型不打包进安装包**。首次启动若检测到推荐依赖缺失，会弹出「初始化依赖」向导：

1. **默认勾选**推荐项：PaddleOCR 模型（约 20MB，图片/扫描 PDF 识别）与 BGE-small（约 95MB，离线语义搜索）
2. 点击「全部安装」→ 从**国内镜像**下载并显示实时进度；安装完成后自动进入应用
3. 可点「跳过」先进应用——之后随时到 **设置 → 依赖中心** 补装（顶部也会出现黄色缺依赖提示条）

> 开发版（`npm run tauri dev`）直接使用仓库内模型，不会触发该向导。
> Windows 的 OCR 若走系统「Windows OCR」，向导会检测是否缺少中文等语言包并给出补装指引。

## 步骤 7：了解底部状态栏

底部状态栏实时显示系统状态：

| 信息 | 说明 |
|------|------|
| 文件总数 | 当前资料库中的文件总数 |
| 已索引 | 成功提取文字并加入索引的文件数 |
| 待处理 | 排队等待索引的文件数 |
| 错误 | 索引失败的文件数（可点击查看详情） |
| OCR 进度 | 正在进行中的 OCR 任务进度 |
| 上次扫描时间 | 最近一次扫描完成的时间 |

## 步骤 8：了解界面布局

启动后，你会看到 Link-Searcher 的主界面，分为三个部分：

**左侧导航栏**：列出所有功能页面，从上到下依次为：
| 链接 | 说明 |
|------|------|
| 搜索 🔍 | 全文搜索入口 |
| AI 聊天 💬 | AI 对话式文档检索 |
| 浏览 📂 | 文件表格视图 |
| 资料库 📚 | 资料库目录管理 |
| 索引状态 📊 | 扫描进度与统计 |
| 日志 📋 | 操作日志 |
| 文件类型 📄 | 各格式文件统计 |
| 设置 ⚙️ | 应用配置 |

导航栏底部显示当前主题状态按钮（「浅色」「深色」或「跟随系统」），点击可切换主题。

**中间主区域**：根据所选页面显示对应的内容。

**底部状态栏**：始终显示汇总信息，如：
```
11671 个文件 | 11666 已索引 | 5 错误 | 2467/2833 已完成 OCR | 上次扫描: 06:19:47
```

## 步骤 9：切换主题

点击左侧导航栏底部的主题按钮，可在「浅色」「深色」「跟随系统」三种主题间切换。按钮文字会随当前主题变化。
